# Security Policy

## Supported Versions

The repository has no published GitHub releases as of 2026-11-08. No version-support matrix or security-update window has been declared.

Do not infer a supported-version guarantee from a branch, package version, README claim, or development status. Release support must be documented against immutable release tags after an owner approves a support window.

## Reporting a Vulnerability

Do not publish vulnerability details, exploit code, credentials, personal data, or sensitive logs in public issues, discussions, or pull requests.

A dedicated private reporting channel and GitHub private vulnerability reporting availability have not been verified for this repository. Do not assume that the GitHub private advisory form is enabled.

Until a private intake channel is confirmed, contact the repository owner using the contact method publicly listed on the [cvsz GitHub profile](https://github.com/cvsz) and request a private reporting channel. Send only the request for a secure channel; do not include vulnerability details until that channel is confirmed.

## Response Expectations

No acknowledgement, update, or remediation SLA is currently published. Response timing must not be assumed. The repository owner must establish an accountable security contact and response process before publishing service-level commitments.

## Coordinated Disclosure

Coordinate disclosure with the repository owner. Do not publicly disclose exploit details or unpatched vulnerability information before an agreed mitigation or disclosure date. Do not include secrets or customer data in reports.
